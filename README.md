### 🌸 [Iris API — RESTful Flower Dataset API](https://github.com/Mohanssk/Iris-API)
> A clean, production-ready **REST API** serving the classic Iris flower dataset with 150 records across 3 species.

- 🔗 Endpoints: `GET /iris` (all records) · `GET /iris/:id` (by ID 1–150)
- 📦 Returns structured JSON with sepal/petal dimensions and species
- ⚡ Built and deployed on **Vercel** for zero-latency access
- 🌐 **Live Demo:** [iris-api-mk7.vercel.app](https://iris-api-mk7.vercel.app)
